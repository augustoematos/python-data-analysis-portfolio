# python-data-analysis-portfolio
A portfolio of data analysis projects built with Python to practice and develop professional skills. Includes exploratory data analysis, data visualization, and insights from diverse datasets. Projects use tools such as pandas, Matplotlib, and Jupyter/Google Colab.

## Projects

### Immigration to Canada: Brazil and Argentina (1980–2013)

An exploratory analysis comparing immigration from Brazil and Argentina to Canada from 1980 through 2013, with a line chart of annual immigrant counts.

- **Notebook:** `brazilian_immigration_to_canada_1980_2013.ipynb`
- **Data source:** [Immigration to Canada — Kaggle](https://www.kaggle.com/datasets/ammaraahmad/immigration-to-canada)
- **Dataset file used:** `canadian_immegration_data.csv`

Download the dataset from Kaggle and make the CSV available to the notebook. In Google Colab, update the file path in the notebook if you store the CSV in a different location.

## Tools

- Python
- pandas
- Matplotlib
- Jupyter Notebook / Google Colab

## Running a notebook

1. Download the relevant dataset from its source.
2. Open the notebook in Google Colab or Jupyter.
3. Adjust the dataset path if needed.
4. Run the cells from top to bottom.
